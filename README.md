# Todo App

A simple Todo List application built with HTML, CSS, and JavaScript. It lets users add tasks, mark them as complete, and delete them — all synced with a server using the Fetch API.

## Features

- Fetches and displays all todos from the server on page load
- Add new todos (POST)
- Mark todos as complete using a checkbox (PUT)
- Delete todos (DELETE)
- Clean, simple UI

## Tech Stack

- HTML
- CSS
- JavaScript (Fetch API — GET, POST, PUT, DELETE)
- JSONPlaceholder (fake REST API for testing)

## How to Run

1. Clone this repository
2. Open `index.html` in your browser
3. Start adding, completing, and deleting your todos!

## Notes

This project uses JSONPlaceholder, a free fake API for testing and prototyping. Changes (add/update/delete) are simulated by the server and won't persist after a page refresh.
